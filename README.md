# Vexo

Free games, music, movies countdowns, Vexo AI and more. Everything is in `index.html`.

## Put it online with GitHub Pages (free)

1. Sign in at github.com and click **New repository**.
2. Name it (for example `vexo`), set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**, then drag in `index.html`, `admin.html` and this `README.md`. Click **Commit changes**.
4. Go to **Settings**, then **Pages**. Under **Branch**, pick **main** and **/(root)**, then click **Save**.
5. Wait 1 to 2 minutes and refresh. Your link shows at the top of that page, like
   `https://YOUR-NAME.github.io/vexo/`

## Updating the site later

Upload the new `index.html` the same way (Add file, then Upload files) and commit. GitHub replaces the old one and the site updates in a minute or two.

## Files

- `index.html`: the whole site (games, music, movies, Vexo AI, search, levels and badges).
- `admin.html`: the owner page for events.
